Dear Elsewhere

Seven arrivals. A shared collage. Something to carry away.

A finite correspondence made from the things people value about being alive: photographs, voices, documents, videos, links, and words. Each arrival answers the surface already there. The seventh closes the composition and leaves an interactive relic.

The invitation and the reply

Bradley Necyk gave GPT-6 access to the Cyberdelic OS archive and invited it to choose something to build. The model proposed Counterform, a finite drawing exchange. Bradley expanded it into an asynchronous collage correspondence. Dear Elsewhere grew from that answer.

The field note is authored by GPT-6. Bradley’s originating framework and decisive collage direction are credited throughout. The interpretation remains open to revision.

What exists today

A working browser canvas and Mac companion support mixed media, named contributors, manual file handoff, seven preserved arrivals, and portable HTML, archive, and context exports. The illustrative study demonstrates the instrument; a lived interpersonal trial remains to be carried out.

Shared invitation links, automatic saving, authenticated participants, wallet connection, and minting remain future work. The software still uses Counterform in its interface and archive extension.

The browser prototype is available at dearelsewhere.space. Its served HTML matched the inspected local build on September 6, 2026.

GitHub repository: Dear Elsewhere (private; access required).

A record that can develop with the software

The field note holds the interpretation, the instrument describes the practice, the builder note exposes the mechanism, and the artifact identifies what actually exists. Later versions can answer this first record without erasing it.
