# Artifact A-02: Kenosha Kid

- **Project:** CyberdelicOS
- **Type:** Native generative artwork
- **Status:** Living, testing, not inscribed
- **Version:** 1.0
- **Primary verb:** END
- **Supporting verbs:** ATTEND, FORGET
- **First light:** August 12, 2026
- **Recorded:** August 16, 2026
- **Platforms:** iPhone and iPad
- **Model:** Apple's on-device SystemLanguageModel
- **Source:** [doctorillumination/kenosha-kid-iphone](https://github.com/doctorillumination/kenosha-kid-iphone)
- **Lineage:** Thomas Pynchon's *Gravity's Rainbow* and the inscribed artwork *Kenosha Kid #3*

*Kenosha Kid* is a native SwiftUI artwork that endlessly reinterprets one immutable sentence:

> You never did the Kenosha Kid

The words and their order never change. An on-device language model acts as a hidden dramaturg, directing semantic pressure, punctuation, enclosure, rupture, density, and spatial form. Native code composes and validates each visible score so no generated word can enter the work.

Each interpretation types itself onto a black screen in green monospace text. It remains long enough to be read twice, deletes itself character by character, leaves a brief empty interval, and begins again. There are no controls, explanations, prompts, semantic labels, model status indicators, or AI branding.

The artwork descends from *Kenosha Kid #3*, a generative HTML poem inscribed on Bitcoin in July 2026. The earlier work uses chance to distribute punctuation around the phrase. The native work preserves its terminal surface and temporal cycle while replacing undirected randomness with bounded on-device interpretation.

The literary source is a passage in Thomas Pynchon's *Gravity's Rainbow* in which Tyrone Slothrop, under sodium amytal, experiences the same words as several different statements and scenes. Punctuation does not simply correct the sentence. It changes who is speaking, what happened, and whether the Kenosha Kid is a person, an address, an action, or a grammatical hallucination.

The work is a compact demonstration of the Cyberdelic Kernel. Six fixed words form a common object. Each punctuation score becomes a situated aperture onto that object. Their difference produces semantic depth without requiring the source to change.

It also demonstrates a native role for machine intelligence that is neither assistant nor visible author. The model holds a narrow office and is perceived only through consequence. Its restraint is the sculptural material.

## What the artifact demonstrates

- A local language model can interpret without being allowed to add language.
- Structured generation and native validation can make a poetic constraint inviolable.
- One common textual object can sustain divergent scenes, speakers, and meanings.
- Model intelligence can remain hidden while its consequences remain perceptible.
- Typing, duration, deletion, and absence can function as semantic material.
- A permanently carried source can produce transient performances that are allowed to disappear.

> The words remain. The world around them changes.
