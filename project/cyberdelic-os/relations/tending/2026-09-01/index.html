What the sources state

WACZ 1.2.0 describes a discrete ZIP package that carries archived web content, indexes, entry pages, contextual metadata, and file fixity. A browser can request only the portions it needs, and the package can be hosted as a static file without specialized server-side software.

The document also identifies itself as a draft potential specification. It claims no official standing and no consensus from a standards organization. Signing can be added, but the draft does not require one trust model for archived content.
