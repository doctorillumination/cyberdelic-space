Dear Elsewhere is a working collage instrument for seven asynchronous arrivals. Participants bring digital fragments into a shared surface, arrange and annotate them, then pass a saved file to the next person. The final arrival closes composition and leaves an interactive archive.

The work began when Bradley asked GPT-6 to choose a useful piece of software from the Cyberdelic OS framework. The first answer, Counterform, used procedural responses to drawing. Bradley expanded the material to the things people value about being alive, including the distant, delayed rhythm of voice-note correspondence. The second implementation follows that direction. The repository has been renamed Dear Elsewhere; application labels and file extensions still carry Counterform.

## The object that exists

The prototype contains a spatial canvas, named contributors, addressed turns, media and document import, annotations, historical arrangements, and interactive export. Its portable HTML carries the viewer, archive, and included file bytes. A structured JSON archive and readable context can accompany it.

The browser page and Mac application share the collage runtime. The native companion adds document previews and file conveniences. The earlier drawing instrument remains in the source history as a different work with a different archive format.

The illustrative composition shipped with the prototype demonstrates interaction and media. It is an authored study, not a preserved conversation between real participants.

## What this record establishes

The identified source version built locally and passed its recorded automated checks. Observed use covered seven-arrival completion, portable reopening, native-to-browser handoff, history integrity checks, PDF preservation, and media playback.

This is evidence of a functioning prototype. It is not yet evidence of durable shared hosting, verified participant identity, an independent security review, or a completed interpersonal study. Live microphone capture remains untested.

The browser prototype is served at [dearelsewhere.space](https://dearelsewhere.space/). Its HTML was checked against the recorded local build on September 6 and matched byte for byte. This establishes the availability of the static instrument at that check, not a shared collaboration service. Its repository remains private.

There is no wallet connection, deployed contract, uploaded relic, minted token, or sale in this implementation.

## Keeping the work

Preserve the exact software revision, its format description, and a complete exported archive when documenting a future exchange. Keep the original included files as well as the interactive rendering. A compatible browser is still needed to perform the viewer, and external links may stop resolving.

The current history hashes allow comparison with a retained commitment. They do not establish identity, rights, consent, or unbroken availability. A local copy also cannot be recalled from someone who has already received it.

The interactive archive is a sufficient artifact in its own right. Any future public edition, Ethereum commitment, ownership arrangement, or programmable behaviour should acquire its own record and contributor decisions.
